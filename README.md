# Reaction Test

A simple reaction time test that measures how quickly you can respond when a red box turns green.

## Features

- ⚡ Reaction time measurement in milliseconds
- 🎯 Randomized reaction delay
- 🚫 Early-click detection
- 🏆 Global leaderboard
- 💾 Save scores with a username

## How It Works

1. Click **Start** to begin the test.
2. Wait for the red box to turn green.
3. Click as quickly as possible.
4. Your reaction time is displayed in milliseconds.
5. Optionally save your score to the leaderboard.
